# C01 — Owner Acceptance and DWG Conversion

- Status: `HOLD_R01`
- Dependency: exact R01 PASS

## Scope

Present the reviewed drawing to the owner for visual and engineering acceptance. If accepted, release the DXF and authorize AutoCAD/BricsCAD Save As DWG.

## Acceptance

Owner confirms content, intended use and release status. Final files are hash-recorded and linked to the accepted revision.

## Stop

Do not release or describe a DWG as final without this explicit acceptance.
